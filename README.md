# cherkashynapiano.com

Oficiální webová prezentace klavíristky Iriny Cherkashyny.

## Technologie

* Next.js
* TypeScript
* SCSS
* Strapi CMS
* PostgreSQL
* Prisma ORM

## Struktura projektu

```text
packages/
├── web/   # Frontend aplikace
└── cms/   # Administrace (Strapi CMS)
```

## Lokální spuštění

Instalace závislostí:

```bash
npm install
```

Spuštění vývojového prostředí:

```bash
npm run dev
```
