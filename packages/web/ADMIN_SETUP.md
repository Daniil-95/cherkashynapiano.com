# Admin Panel Setup Guide

Это руководство описывает, как установить и использовать административную панель проекта cherkashynapiano.com.

## Требования

- Node.js 18+
- PostgreSQL 12+
- npm или yarn

## Установка

### 1. Установка зависимостей

```bash
cd packages/web
npm install
```

### 2. Настройка переменных окружения

Скопируйте `.env.example` в `.env.local`:

```bash
cp .env.example .env.local
```

Отредактируйте `.env.local` и заполните:

```env
# PostgreSQL подключение
DATABASE_URL="postgresql://user:password@localhost:5432/cherkashynapiano"

# JWT токен (сгенерируйте случайную строку)
JWT_SECRET="generated-random-secret-key"

# Ключ для первоначальной установки админа
ADMIN_SETUP_KEY="your-setup-key"
```

### 3. Создание базы данных

```bash
npm run prisma migrate dev --name init
```

Это создаст все необходимые таблицы в PostgreSQL.

### 4. Создание первого администратора

Откройте в браузере:
```
http://localhost:3000/admin/setup
```

Отправьте POST запрос с вашим ключом:

```bash
curl -X POST http://localhost:3000/admin/setup \
  -H "Content-Type: application/json" \
  -d '{
    "key": "your-setup-key",
    "email": "admin@example.com",
    "password": "secure-password"
  }'
```

После создания первого администратора, `/admin/setup` будет недоступен.

### 5. Запуск разработочного сервера

```bash
npm run dev
```

Откройте [http://localhost:3000/admin](http://localhost:3000/admin) и введите учетные данные администратора.

## Структура Admin Panel

### Маршруты

```
/admin                          # Дашборд (требует авторизации)
/admin/login                    # Страница входа (публичная)
/admin/setup                    # Создание первого админа (публичная)
/admin/biography                # Управление биографией
/admin/repertoire               # Управление репертуаром
/admin/concerts                 # Управление концертами
/admin/photos                   # Управление фотографиями
/admin/videos                   # Управление видео
/admin/messages                 # Просмотр сообщений контактной формы
```

### Сущности

#### Biography (Биография)
- Главная информация о пианисте
- Одна запись на весь сайт
- Содержит: название, описание, URL профильного изображения

#### Repertoire (Репертуар)
- Список музыкальных произведений
- Содержит: название, композитор, год, длительность, описание

#### Concert (Концерты)
- Информация о предстоящих и прошедших концертах
- Содержит: название, дата, время, город, место, описание, флаг "предстоящий"

#### Photo (Фото)
- Галерея фотографий
- Содержит: название, URL изображения, категория, описание, порядок сортировки

#### Video (Видео)
- Видеогалерея (YouTube)
- Содержит: название, YouTube ID, категория, описание, порядок сортировки

#### ContactMessage (Сообщения)
- Сообщения, отправленные через контактную форму
- Доступны только для чтения
- Можно отметить как прочитанное/непрочитанное
- Можно удалить

## Аутентификация

### JWT Токены

- Срок действия: 7 дней
- Хранится в httpOnly cookie с именем `admin_session`
- Автоматически отправляется с каждым запросом

### Безопасность

- Пароли хешируются с помощью bcrypt (12 раундов)
- Все API маршруты требуют валидной сессии
- Middleware защищает все маршруты `/admin/*` кроме `/admin/login` и `/admin/setup`

## Использование

### Создание записей

1. Перейдите в соответствующий раздел (например, `/admin/concerts`)
2. Заполните форму "Добавить новое [сущность]"
3. Нажмите "Добавить"
4. При успехе появится баннер "Изменения сохранены" и страница автоматически обновится

### Редактирование записей

1. Найдите запись в списке
2. Отредактируйте поля в форме под записью
3. Нажмите "Сохранить"

### Удаление записей

1. Нажмите кнопку "Удалить" под записью
2. Подтвердите действие в диалоговом окне

### Просмотр сообщений

1. Перейдите в `/admin/messages`
2. Отметьте сообщения как прочитанные/непрочитанные
3. Удалите ненужные сообщения

## API

Все административные операции используют Server Actions (встроенные в Next.js функции).

### Примеры

Создание концерта через форму:

```html
<form action={createConcertAction}>
  <input name="title" required />
  <input name="date" type="date" required />
  <input name="location" required />
  <input name="venue" required />
  <button type="submit">Добавить</button>
</form>
```

## Стилизация

Admin panel использует SCSS modules с предопределённой цветовой схемой:

- `#111827` — основной текст, кнопки
- `#ffffff` — фон карточек
- `#f3f4f6` — фон страницы
- `#d1d5db` — границы
- `#047857` — успех
- `#b91c1c` — опасные действия

## Мобильная адаптивность

Admin panel полностью адаптирован для мобильных устройств:

- На мобильных устройствах (<768px) сайдбар превращается в drawer-меню
- Меню открывается/закрывается клавишей ESC
- Автоматическое закрытие при изменении размера окна
- Оптимизированные макеты для маленьких экранов

## Производственная развёртка

### Переменные окружения

Обязательно установите в production:

```env
NODE_ENV=production
JWT_SECRET=your-generated-secret-key
ADMIN_SETUP_KEY=use-once-then-remove
DATABASE_URL=production-database-url
```

### Безопасность

1. Сгенерируйте сильный JWT_SECRET
2. Используйте уникальный ADMIN_SETUP_KEY
3. Используйте HTTPS для всех соединений
4. Регулярно обновляйте зависимости
5. Резервируйте базу данных

### Миграции БД

```bash
npm run prisma migrate deploy
```

## Заметки о разработке

### Добавление новой сущности

1. Добавьте модель в `prisma/schema.prisma`
2. Запустите миграцию: `npm run prisma migrate dev`
3. Создайте файл действий: `app/admin/[entity]/actions.ts`
4. Создайте страницу: `app/admin/[entity]/page.tsx`
5. Добавьте пункт меню в `components/admin/AdminShell.tsx`
6. Создайте стили: `styles/admin/[entity].module.scss` (если нужно)

### Команды Prisma

```bash
# Синхронизация схемы с БД
npm run prisma db push

# Запуск миграций
npm run prisma migrate dev

# Студия Prisma (браузер)
npm run prisma studio

# Генерация типов
npm run prisma generate
```

## Решение проблем

### "Ошибка подключения к БД"

Убедитесь, что:
1. PostgreSQL запущен
2. DATABASE_URL правильно заполнен
3. База данных создана

### "Сеанс истек"

JWT токен истекает через 7 дней. Войдите заново с вашими учетными данными.

### "Ошибка валидации формы"

Проверьте, что все обязательные поля заполнены. Сообщения об ошибках видны под полями и в консоли браузера.
